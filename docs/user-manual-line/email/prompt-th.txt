Prompt สำหรับให้ AI (Claude / Gemini ฯลฯ) ร่างอีเมลส่งคู่มือให้คู่ค้า
=====================================================================
คัดลอกข้อความด้านล่างไปวางในผู้ช่วย AI แล้วปรับได้ตามต้องการ

---------------------------------------------------------------------
ช่วยเขียนอีเมลภาษาไทยแบบมืออาชีพ สุภาพ กระชับ อ่านง่าย โทนทางการแต่เป็นมิตร
สำหรับส่งให้ "คู่ค้า / ตัวแทนจำหน่าย (Dealer)" เพื่อแนะนำการเริ่มใช้งานระบบ
และมีไฟล์คู่มือ PDF แนบไปด้วย

ข้อมูลประกอบ:
- ระบบ: Vizzel Sales — ระบบบริหารงานขาย (CRM) สำหรับงานหน่วยงานราชการ ใช้งานผ่าน LINE บนมือถือ ไม่ต้องติดตั้งแอปเพิ่ม
- ผู้รับ: คู่ค้า / ตัวแทนจำหน่าย
- วิธีเริ่มใช้งาน 3 ขั้นตอน:
  1) เพิ่มเพื่อน LINE บริษัท "Vizzel Track Support" แล้วแตะปุ่ม "สำหรับคู่ค้า" บน Rich Menu
     (ลิงก์เพิ่มเพื่อน: https://lin.ee/UAOQyx0)
  2) ลงทะเบียนใช้งานครั้งแรก และกรอก Invite Code ที่ได้รับจากบริษัท
  3) ยืนยันอีเมลด้วยรหัส OTP 6 หลัก แล้วเริ่มใช้งานเมนูหลักได้ทันที
- ไฟล์แนบ: Vizzel-Sales-LINE-User-Manual.pdf (คู่มือฉบับเต็ม: เข้าสู่ระบบ · เมนูหลัก · สร้าง/กรอกโครงการ · ลงนัดหมาย · แนบไฟล์ · ข้อควรระวัง)
- โทน: เป็นทางการแต่เป็นมิตร ดูมืออาชีพ ความยาวพอดีอีเมล ไม่ยืดเยื้อ

สิ่งที่ต้องการ:
1) หัวข้ออีเมล (Subject) ให้เลือก 3 แบบ
2) เนื้อหาอีเมล ประกอบด้วย: คำขึ้นต้น → ย่อหน้าแนะนำระบบสั้น ๆ → ขั้นตอนเริ่มใช้งาน 3 ข้อ (เรียงเป็นลำดับ)
   → ประโยคชวนเปิดใช้งานพร้อมลิงก์ LINE → หมายเหตุว่ามีไฟล์คู่มือ PDF แนบมา → คำลงท้าย + ลงชื่อ "ทีมงาน Vizzel Sales"
3) เว้นวงเล็บให้เติมเอง: [Invite Code], [เบอร์ติดต่อ], [อีเมลบริษัท]
4) จัดรูปแบบให้พร้อมคัดลอกไปวางใน Gmail ได้ทันที (ข้อความล้วน อ่านง่าย เว้นบรรทัดเหมาะสม)
